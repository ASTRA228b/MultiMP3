# MultiMP3 v1.3.0

The first public release of **MultiMP3 — A ChudGPT App**, retaining the existing application's 1.3.0 version.

MultiMP3 is a Windows desktop utility for organizing supported links, downloading permitted audio, converting it to MP3 and managing a local collection.

- Batch queues for YouTube videos, public playlists and YouTube Music albums.
- Named album folders and selectable MP3 quality, including Best Available VBR.
- Download-folder management, safe filenames and protection against overwriting existing audio.
- Concurrent processing, pause, cancellation, retries, history and per-item error logging. Failed items do not stop the remaining queue.
- Amazon Music mode for exact-copy organization of purchased MP3 files already on disk.
- ChudGPT ecosystem branding and About page, preserving MultiMP3's waveform identity.

## Install

Download the Windows x64 ZIP, extract it completely, run **Setup-Engine.cmd**, then open **MultiMP3.exe**. Optional **Create-Shortcut.cmd** adds a desktop shortcut. The ZIP includes .NET and its license notices. Media tools install separately from upstream with published SHA-256 verification; they are not redistributed in this ZIP. A checksum file is provided for the ZIP itself.

## Verified

Release build, 50 regression checks with real audio fixtures, isolated UI workflow tests, normal/minimum window captures, production startup, native folder selection and first-run tool setup passed. See the repository's release verification document for scope.

## Limitations

Windows x64 only; the app is unsigned and needs internet access for setup and remote downloads. Upstream extractor changes can require tool updates. No Amazon subscription streaming, DRM bypass, private/authenticated media, infinite radio mixes or ongoing livestreams. Use one instance per library. Only download media you own or have permission to save.

MultiMP3 source and original artwork are MIT licensed; third-party components retain their own licenses.
